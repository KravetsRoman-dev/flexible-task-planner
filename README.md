# Flexible Task Planner — VS Code extension

Гибко настраиваемый плагин, который находит задачи в комментариях исходного кода и автоматически формирует план работ с приоритетами.

## Быстрый запуск

1. Установить **Node.js 20+**, npm и **VS Code**.
2. Открыть **папку `flexible-task-planner`** в VS Code.
3. В терминале выполнить `npm install`, затем `npm run compile`.
4. Нажать **F5** (Run Extension) — откроется второе окно VS Code (Extension Development Host).
5. Во втором окне открыть любую папку с исходниками. Слева открыть **Task Planner** (иконка списка с галочкой).
6. Нажать на шестерёнку в заголовке панели или вызвать **Task Planner: Configure** через `Ctrl+Shift+P`.
7. Нажать **Refresh**, чтобы пересканировать проект (при сохранении файлов список обычно обновляется сам).

Для установки без среды разработки: `npx @vscode/vsce package` (или `npm run package`) создаст `.vsix`. Затем в VS Code: Extensions → `...` → Install from VSIX. Для упаковки может потребоваться установить и настроить инструменты npm.

## Пример

```cpp
// BUG: Исправить выход за границы массива
// TODO: Реализовать бинарный поиск
// OPTIMIZE: Ускорить сортировку
// CUSTOM_TASK: Добавить документацию
```

Добавьте `CUSTOM_TASK` в окне Configure, задайте ему приоритет. Задачи появятся в **Found Tasks** (по файлам) и **Work Plan** (по приоритетам). Нажатие на задачу перемещает редактор на исходную строку. Команда **Task Planner: Export Plan as Markdown** сохраняет план в файл `.md`.

## Настройки

Все параметры доступны в GUI **Task Planner: Configure** и хранятся в VS Code workspace settings (`.vscode/settings.json`), если открыта папка проекта, или в глобальных настройках, если папки нет.

- `ftp.markers`: произвольные имена (буквы, цифры, `_`, `-`) и приоритеты от 1 до 9.
- `ftp.include`, `ftp.exclude`: glob-шаблоны выбора файлов и исключений.
- `ftp.commentPrefixes`: текстовые префиксы комментариев, один на строку.
- `ftp.scanAnywhere`: искать метки в любом месте строки, даже вне комментариев.
- `ftp.caseSensitive`: учитывать регистр.
- `ftp.autoRefresh`: автоматическое пересканирование после сохранения файла / изменений структуры проекта.
- `ftp.groupTasksByFile`: группировка Found Tasks по файлам.
- `ftp.maxFiles`, `ftp.maxFileKB`: ограничения сканирования.

## Архитектура

`src/scanner.ts` — независимый от VS Code поиск маркеров, валидация конфигурации; `src/extension.ts` — интеграция с VS Code, сканирование проекта, два дерева задач, окно Webview с настройками, экспорт Markdown. `test/scanner.test.cjs` — unit-тесты.

## Проверка

`npm test` — компиляция и unit-тесты. Для проверки интерфейса используйте F5.

## Ограничения первой версии

- Комментарии определяются по наличию настроенного префикса в строке. Это **эвристика**, а не полноценный разбор синтаксиса языка: маркеры внутри строк, которые содержат `//`, могут распознаваться ошибочно.
- Обрабатывается один маркер на строку. Блочные комментарии поддерживаются частично: строки должны содержать префикс (`/*`, `*` и т. п.).
- План = сортировка/группировка по приоритету, а не автоматическое определение зависимостей и сроков.
- Читаются UTF-8 файлы, большие или бинарные файлы пропускаются; есть лимит количества файлов.
- В автоматическом режиме анализируются изменения **сохранённых** файлов. Несохранённые правки не учитываются.
